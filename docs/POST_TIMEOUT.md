# Таймауты POST

[English](POST_TIMEOUT.en.md)

Три сценария в [test_post_timeout.py](../hil/common/tests/board/test_post_timeout.py):
`HW_POST_RSTCAL_TIMEOUT`, `HW_POST_CAL_TIMEOUT`, `HW_POST_EOC_TIMEOUT`.
Прошивка не меняется. Испытываются три реальные ветви отказа POST на WeAct F103CB/OpenOCD.

Точка определяется по уникальной строке while и DWARF. Перед работой проверяется узкий
контракт инструкций ELF: загрузка адреса, чтение CR2/SR, TST нужной маски и направление
ветвления. Изменение компилятора может привести к отказу preflight; автоматически угадывать
новый машинный код нельзя. Отрицательные host-тесты проверяют эту защиту.

В регистре CPU подменяется только результат уже выполненного чтения MMIO:
RSTCAL/CAL остаются логически заняты либо EOC логически отсутствует. Сценарий не пишет
аппаратные флаги, не изменяет Flash, не переводит PC и не подменяет возврат adcInit/convert.
Возврат board::millis задаёт время start+10 и start+11. На 10 мс требуется повторный вход
в тот же цикл, на 11 — настоящий false из функции и достижение общей очистки post::run.
Затем проверяются PostAdcTimeout, завершение setup, отсутствие отсчётов и сброс ADON/TSVREFE.
finally удаляет точки, сбрасывает MCU и требует штатного PostOk.

Границы опыта: это модель результата чтения зависшего периферийного состояния, а не
физический отказ ADC. Реальные RSTCAL/CAL могут уже завершиться. EOC проверяется для
первого отсчёта VREFINT; отдельный отказ температурного преобразования и более позднего
отсчёта не заявляются. 10/11 — программные значения времени, не длительность SWD-опыта.

Карта связывает каждую ветвь while с подтверждённым ожиданием и возвратом false,
очистку ADC — с маской отключения, статус — с PostAdcTimeout. Пустые строки и комментарии
не используются. Остальные утверждения доступны в HTML по сценарию.

Проверено 15.10.2026: 28/28 WeAct HW PASS, capture сохранён; 29/29 подготовки F103CB host PASS; три unit-теста preflight и четыре проверки экспорта/отчёта PASS. Карта: 94 подтверждённые связи на 72 строках. Исправления прошивки не потребовались; другие платы не проверялись.
