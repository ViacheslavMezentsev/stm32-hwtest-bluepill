# Ошибка DMA: TE и TE+TC

[English](DMA_ERROR.en.md) · [ADC/DMA](ADC_DMA.md)

Сценарии `HW_DMA_ERROR` и `HW_DMA_ERROR_TC` в
[test_dma_error.py](../hil/common/tests/board/test_dma_error.py) проверяют обработчик
на WeAct F103CB через OpenOCD/ST-Link. Прошивка и ядро stm32-gdbtest не изменены.

После первого настоящего принятого блока сценарий останавливается в следующем настоящем
DMA IRQ, после чтения ISR и остановки передачи. Проверяются номер точки, кадр, исключение,
исходный TC, выключенные ADC/DMA и ready=0. Локальная переменная `status` подменяется
на TEIF1 или TEIF1|TCIF1 с обратным чтением. Read-only ISR не записывается;
не используются некорректные адреса DMA. Якорь строки ищется в исходнике, а не задан числом.

До следующего arm ожидаются: dma_errors=1, ready=0, accepted=1, irq_count=1,
normal=0 и MeasurementFault, выключенные ADC/DMA, очищенные флаги канала, timeouts=0.
Таким образом, даже одновременный TC не публикует ошибочный блок. Следующие две реальные
передачи дают accepted/irq_count=2 и 3, норму и прежний единственный dma_errors.
finally выполняет reset, достигает loop и проверяет очистку состояния монитора.

Это проверка решения по снимку статуса, не физического возникновения TE, не остановки
частично завершённой передачи и не гонки IRQ с таймаутом. Настоящий периферийный статус
до подмены содержит TC; аппаратный флаг TE в этом опыте не генерируется.

Первый опыт завершился FAIL до инъекции: reach(file:line) закреплённой версии проверяет
имя кадра как имя функции. Он заменён на breakpoint/resume с явными проверками точки
и кадра. Исходный результат сохранён; это ошибка сценария, не дефект DMA.

Карта добавляет по четыре связи для каждого опыта: приоритет TE, счётчик ошибки,
публикация отказа и восстановленное принятие блока. Отсутствие публикации ready и
остальные утверждения видны в подробном отчёте, даже без отдельной окрашенной строки.

Повторение: `--test HW_DMA_ERROR` / `--test HW_DMA_ERROR_TC` штатного runner либо
выбор этих сценариев в задаче VS Code. После свежей кампании:

```powershell
python hil/tools/ddtt_export.py --runs build/<campaign>/runs
```

Проверено 15.10.2026: WeAct F103CB/OpenOCD, 25/25 HW PASS с сохранённым capture; подготовка F103CB host 26/26 PASS. Четыре unit-проверки экспортёра/отчёта прошли. Свежая карта: 82 CONFIRMED на 68 строках, без FAILED/UNKNOWN. Исправление прошивки не понадобилось. Другие аппаратные профили на этом этапе не проверялись.
