## [Unreleased]

- Приёмка финального кандидата 0.5.0: подмодуль stm32-gdbtest переведён на 8fdbb58 (версия 0.5.0, API_VERSION=3), копии навыков обновлены (формат Agent Skills, TTDD). Сценарии и SVD не менялись; проверки host — на этом gitlink, аппаратные — в кампании P5b.
- Миграция 28 HIL-сценариев на API 3 кандидата 0.5.0 (cb03e86): явные MMIO-доступы, проектный SVD F103C8/CB, согласие на эффекты SysTick/USART/ADC, офлайн-проверки прав и очистки, сверка 35 регистров с ELF. Копии навыков и фикстура DDTT обновлены. Прошивка не менялась; аппаратная приёмка миграции ещё не выполнена.

- Добавлен отдельный Renode/GDB CI-пример запуска: эмуляторная карта DDTT, переносимый HTML/LCOV/Cobertura, аннотации строк и ручная публикация Pages (по умолчанию выключена).

- Добавлен переносимый просмотр исходников с раскраской DDTT, ссылками GitHub по SHA, публичной сводкой разрешённых полей, относительными LCOV/Cobertura и снимками входов кампании. Публикация не включена.

- Добавлены таймауты POST RSTCAL/CAL/EOC: границы 10/11 мс, очистка ADC, штатный перезапуск, preflight инструкций ELF и 12 связей DDTT. Прошивка не изменена.

- Добавлены сценарии TE и TE+TC обработчика DMA с восстановлением настоящего сбора и восемью связями DDTT; прошивка не изменена.

- Кнопка: устойчивое удержание включает LED, отпускание возвращает индикацию измерений. Два HIL-сценария, 23/23 WeAct PASS; DDTT 74 связи / 65 строк. Экспорт отвергает комментарии и устаревшие привязки, очищает прежний LCOV при ошибке.

- Индикация измерений: ожидание/норма/отказ, восстановление после ошибочного блока; три HIL-сценария, 21/21 WeAct PASS и карта DDTT 64/55. HTML в стиле GitHub с тёмной темой по умолчанию и круглой кнопкой тёмная/светлая/авто.

- Добавлен периодический ADC1/DMA1-сбор восьми пар, усреднение и скалярные фильтры Калмана. Три новых сценария, полная серия WeAct 18/18, host 19/19 обоих профилей. Карта DDTT: 54 связи/49 строк; HTML показывает сценарии, свидетельства и попытки выбранной кампании.

- Добавлены три аппаратных сценария запуска/периферии с русскими комментариями; карта DDTT WeAct PB2 расширена до 33 связей с 28 строками. Подмодуль обновлён до принятого main eb085b3 (после v0.4.1, не релиз 0.4.2). На F103CB/OpenOCD все 15 сценариев PASS; оба профиля: host 16/16.

- Руководство окружения разработчика перенесено из `hil/` в `docs/` в обеих локализациях; ссылки обновлены.

- Упорядочены пресеты f103c8/f103cb-debug/release/hil, задачи VS Code и компактные профили HIL. CI переведён на новые имена и Renode 1.17.0; прошивка не менялась.

- Модуль закреплён на v0.4.0, target schema 2, включён capture; обновлены навыки и добавлен опытный цикл DDTT.
- POST освобождает ADC/датчики и при раннем отказе. Добавлен HW_POST_ADC_CLEANUP; watchpoint старой инъекции VDDA ставится после инициализации результата.

### Added

- Демонстрационный проект stm32-gdbtest на STM32F103: профили `F103C8_PC13` (Blue Pill,
  светодиод PC13) и `F103CB_PB2` (WeAct BluePill-Plus v1.1, светодиод PB2).
- Сборка CMake ≥ 3.25 + Ninja + xPack GCC 14.2.1, только CMSIS (подмножество STM32CubeF1
  v1.8.7), свой скрипт компоновщика; пресеты Debug/Release/HIL для обеих плат, VS Code.
- Прошивка на C++17: `setup()`/`loop()`, мигание светодиодом 1 Гц от HSI 8 МГц, POST через
  АЦП (VDDA по VREFINT и температура кристалла), вывод в USART1 (PA9, 115200).
- HIL: stm32-gdbtest подмодулем, сценарии `HW_BOOT`, `HW_SETUP_DONE`, `HW_POST`, `HW_BLINK`,
  примеры стендов ST-LINK GDB Server, OpenOCD и J-Link для Windows.
- Дымовой тест в Renode 1.16 (`ctest -L emu`, пресеты `Debug_*-emu`): UART, `setup()`, мигание;
  добавляется, только если Renode найден (`BLUEPILL_RENODE_TEST`, в HIL-пресетах выключен).
- Python для HIL ищется сначала по `PATH` (`Python3_FIND_REGISTRY=LAST`).

- Сценарий `HW_BOOT_CMSIS`: проверки загрузки через имена CMSIS (`RCC->CFGR & RCC_CFGR_SWS`,
  `DBGMCU_IDCODE_DEV_ID`, `FLASHSIZE_BASE`) и контракт `cmsis_boot_macros`, который проверяет
  наличие макросов в ELF без платы (`prepare.HW_BOOT_CMSIS`).

### Changed

- stm32-gdbtest обновлён до v0.3.0. Плату описывает конфигурация прогона `hil/sessions/<BOARD>.toml`
  (`SESSION_CONFIG` вместо `PROFILE`): описание MCU, общий `hil/api.toml` с параметрами сценариев и файл
  данных платы `hil/boards/<BOARD>.toml` (вывод и активный уровень светодиода, скорость UART).
- Сценарии переписаны на API 0.3.0: таблицы `check(rows)`, ожидания именами CMSIS и из файла данных платы,
  `read`/`evaluate` вместо `value`, контракты макросов для каждой группы сценариев; стиль проверяет тест модуля.
- Имя платы — глобальный массив `g_board_name` (было `static`): сценарии читают его как C-строку.

### Added

- Сценарии `HW_BOARD_PROFILE` (профиль прогона, строка платы, таблица векторов, отказ чтения периферии),
  `HW_GPIO_CONFIG`, `HW_UART_CONFIG`, `HW_TOGGLE_WRITERS` (точка наблюдения и цепочка кадров),
  `HW_LED_FORCED_STATE` (подмена возврата `ledIsOn()`) и `HW_POST_VDDA_LOW` (подмена отсчёта VREFINT).
- Навыки агентов stm32-gdbtest в `.claude/skills/`: подключение, сценарии, запуск.

### Fixed

- HIL-сборка с `-fno-eliminate-unused-debug-types`: без неё `HW_BOOT_CMSIS` падал на
  `DBGMCU->IDCODE` с ошибкой «No symbol "DBGMCU_TypeDef"» — неиспользуемый тип CMSIS не попадал
  в отладочную информацию.

- `g_led` объявлен `const volatile`: константа подставлялась в код, `--gc-sections` удалял
  переменную, и `HW_BLINK` завершался ошибкой «Missing ELF symbol "g_led"».
- GitHub Actions: форматирование, сборка шести пресетов, Renode, HIL-проверки без платы.
