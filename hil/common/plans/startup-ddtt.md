# Startup DDTT — план

Плата: WeAct BluePill-Plus F103CB_PB2, PB2 active high, локальный OpenOCD/ST-Link.
Разрешены штатная загрузка выбранного ELF и запуск; без mass erase/option bytes и внешних нагрузок.
Код прошивки не меняется. Новые наблюдения: HW_STARTUP_ORDER, HW_SYSTICK_PROGRESS,
HW_ADC_INITIALIZATION; критерии перечислены в ../tests/requirements.md.

До платы: синтаксис, стиль, traceability, prepare, сборки C8/CB. Затем три новых сценария,
при успехе все 15 на CB. Каждая попытка сохраняется отдельно; ERROR обвязки не считается дефектом MCU.
Бюджет — до трёх исправлений сценария, при неверной identity/USB ERROR остановить серию.
Без инъекций и повторного init через call: наблюдаем штатный запуск с помощью reach/frames/read/record.
Записи сохраняются до проверок; CMSIS выражения вычисляются в файле с заголовком устройства.

Карта связывает точное имя проверки с одной строкой исходника; hash ELF и файлов фиксируется
после сборки. Зелёный — подтверждённое ожидание, не трасса исполнения. Непроверенные состояния
и отсутствующие свидетельства не окрашиваются. Старые результаты не подменяются новыми.
Финальная прошивка — исходная демонстрационная; восстановление инъекций не требуется.
