# KEY и целостность карты DDTT

WeAct F103CB/PB2, OpenOCD/ST-Link; схема V1.1: SW2 → R4 330 Ом → PA0, нажатие к 3,3 В.
Использовать pull-down. Прежние измерения floating input не подтверждали полярность;
PB5 отвергнут как плавающий вход. Плата подтверждена владельцем по ускоренному миганию.

Требование владельца: устойчивое удержание кнопки включает LED, отпускание возвращает индикацию
измерений. Дребезг 30 мс на обоих фронтах; удержание не увеличивает счётчик повторно.
Сначала native C++: 29/30 мс, дребезг, отпускание/повтор, wrap. На MCU: GPIO-конфигурация,
виртуальная подмена buttonPressed через ret; временные векторы через параметр update.
Это проверка логики, не длительности физического дребезга. finally reset/reach(loop) снимает инъекции.
Полный аппаратный набор и свежий экспорт карты для одного ELF. Исходного аппаратного FAIL
для отсутствовавшего обработчика нет; не считать Missing symbol подтверждением дефекта.
До экспорта очищать прежний LCOV; отвергать комментарии, пустые и неоднозначные якоря.
Проверить отрицательными host-векторами; старые свидетельства/FAIL не удалять.
Материалы: build/ddtt-button-*. Не менять ядро модуля. Без mass erase/option bytes.
До трёх исправлений и одного диагностического повтора; USB/identity/recovery ERROR останавливают опыт.

Результат: 23/23 WeAct HW PASS; host обоих профилей 24/24; native-векторы и Renode PASS. Свежая карта: 74 подтверждённые связи / 65 строк. Отрицательные контроли комментариев и устаревших исходников прошли. Физическое нажатие остаётся ручной проверкой.
